# CommunityHub Backend

Express backend scaffold for the CommunityHub team project.

## Setup

1. Run `npm install`.
2. Copy `.env.example` to `.env`.
3. Run `npm run dev`.

## Endpoints

- `GET /` - API welcome message
- `GET /api/health` - Health check
- Unknown routes return 404

## Stack

- Node.js
- Express
- JavaScript
